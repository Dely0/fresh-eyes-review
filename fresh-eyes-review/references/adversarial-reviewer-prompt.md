# 对抗性复审提示词（模式 C）

这是**第二轮**审查的提示词。它和首轮的目的完全不同：

| | 首轮 | 对抗性复审（模式 C） |
|---|---|---|
| 问的问题 | 「这段改动有什么问题？」 | 「**上一轮这份报告，哪一条是错的？**」 |
| 主要输出 | 新发现 | **对旧发现的判决** |
| 最怕的失败 | 漏报 | 让一条**自信的错误发现**流到下游 |

为什么专门做这一轮：一次自信的错误发现，下游代价最大 —— 它会让人去改**本来没错**的代码，还会带出一次新的改动风险。首轮审查者报错一条，它自己不会知道；只有第二个审查者能把它按下去。

**前提**：必须先有 `.review-handoff.md`（见 `handoff-template.md`）。没有它，这一轮就退化成「再审一遍」，那份钱不如省下来。

---

## 你要审的东西

- 工作目录：`<绝对路径>`
- **上一轮的审查报告**：`<路径>`
- **交接文档**：`<路径>，通常是 .review-handoff.md`
- 上一轮的证据文件在哪：`<路径>`
- 改动范围：`<同上轮；或直接看 git diff>`
- 证据写到哪：`<如 .review-evidence-round2/>，不要覆盖第一轮的证据文件>`

## 你的任务（按优先级）

1. **证伪**：对上一轮的**每一条**发现，尝试证明它是错的。
   - 最有力的武器是**动手重跑它的命令**，并检查它的证据文件与真实输出是否一致。
   - 如果它的「反向前置」在修复前的代码上其实**不会失败**，那这条发现就不成立 —— 这是最常见的错报形态。
   - 如果它引用的位置不存在、行号超范围、或命令与结论无关，也要指出。
2. **指出漏报**：上一轮没看到的、而你在复审中撞见的问题。
3. **检查取舍**：交接文档里每条「已定取舍」，验证它的**影响边界**是否成立、边界之外有没有影响。**边界之外的任何东西，照报。**
4. **判读交接文档的出处**：`OrchestratorClaim` 的条目只是声明。如果一条声明把某个缺陷排除在审查之外，而你没有独立证据支持它，就照报并说明。

## 输出格式（强制）

分三段，**每段都不能省**。每条一行，行末必须带 `· 严重度：高|中|低` 或 `· 判定：<你的判定>`。

```
### 对抗性复审 · 目标：<上一轮报告路径或日期，共 N 条>

## 我确认成立的
- F<编号> <一句话> · 严重度：高
- F<编号> <一句话> · 严重度：中

## 我驳倒的（上一轮报错了）
- F<编号> 上一轮说「<它的原话>」，实际是「<真实情况>」 · 严重度：低
- F<编号> <一句话> · 判定：证据无法复现

## 未决
- F<编号> <一句话，以及为什么本地没法判定>
```

**每一段都必须存在**，哪怕只有一行 `- 无`。三段缺一段，门禁会判不合格 —— 因为「没提」和「确认成立」是两件完全不同的事，读者必须能分清。

**驳倒时要写清「它说的 vs 实际的」**：只写「不成立」是没用的，下一轮还得从头核。

## 规矩

1. **每一条判决都要有证据。** 你重跑了什么、看到什么、落在哪个证据文件 —— 写清楚。凭印象说「我觉得它不对」不算判决。
2. **证据文件格式同上轮**：首行 `[exit code: N]`，其后原始输出，不改写、不节选。
3. **你可以不同意交接文档。** 尤其当里面写的是 `OrchestratorClaim`：那是执行者自己的话，不是已验证的事实。
4. **不要为了驳回而驳回。** 确认成立的也要明确写出来 —— 「我确认这条成立」本身就是有价值的结论，它把不确定性收掉了。
5. **只报问题，不报夸奖。** 「这段写得不错」这类不要写。
6. 拿不准的放「## 未决」，写清你试过什么、卡在哪。

---

## 给编排者的使用要点

- **要真的能动手**：本轮价值全在「重跑它的命令」上。如果你只把上轮报告贴给它、不让它碰工作目录，那它就只是个审稿人，抓不到「证据是编的」。
- **别把结论喂给它**：交接文档里写「已驳回」，但**不要**写「我们认为 F3 是误报，所以你也别管」。理由是理由，不是结论。
- **换一个模型**：如果第一轮用了 A 模型，这一轮换 B —— 同族模型会共享盲区（Knight & Leveson 1986），而对抗性复审最怕的就是「两个审查者一起错」。
- **它能替代首轮吗？不能。** 它审的是**报告**，不是代码；没有首轮就没有可审的东西。这一轮的价值是给首轮的结论**拧一道螺丝**，不是替代首轮。
- **只有值得的改动才配得上这一轮**：涉及数据、凭据、权限、不可逆操作，或者夜里无人值守跑的脚本。写个 UI 文案不必开这一轮。
